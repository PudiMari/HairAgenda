# Mapeamento de Histórias (User Story Mapping)

Este documento organiza as funcionalidades do HairAgenda sob a perspectiva dos usuários, dividindo-as em personas e versões (Release).

## Estrutura do Story Map

| Atividade | Histórias de Usuário (User Stories) | Prioridade | Status |
| :--- | :--- | :--- | :--- |
| **Onboarding do Profissional** | Como profissional, quero preencher meu perfil (nome, bio, rede social) para que as clientes me identifiquem. | MVP | ✅ Implementado |
| | Como profissional, quero definir se meu perfil está pronto para o público para evitar agendamentos incompletos. | MVP | ✅ Implementado |
| **Gestão de Serviços** | Como profissional, quero cadastrar meus serviços com nome, preço e duração para apresentá-los na vitrine. | MVP | ✅ Implementado |
| | Como profissional, quero editar ou excluir serviços para manter meu catálogo atualizado. | MVP | ✅ Implementado |
| **Gestão de Disponibilidade** | Como profissional, quero definir meus horários de abertura e pausa para automatizar a grade de agendamento. | MVP | ✅ Implementado |
| | Como profissional, quero bloquear datas ou horários específicos manualmente para gerir imprevistos ou folgas. | MVP | ✅ Implementado |
| **Agendamento (Cliente)** | Como cliente, quero acessar o link do profissional e ver os serviços disponíveis para decidir o que marcar. | MVP | ✅ Implementado |
| | Como cliente, quero ver os horários livres em tempo real para escolher o melhor momento para meu atendimento. | MVP | ✅ Implementado |
| | Como cliente, quero confirmar minha reserva informando apenas meu nome e WhatsApp para agilidade. | MVP | ✅ Implementado |
| **Controle de Agenda** | Como profissional, quero visualizar meus agendamentos do dia/semana em um dashboard para me organizar. | MVP | ✅ Implementado |
| | Como profissional, quero cancelar ou confirmar agendamentos pendentes para gerir minha demanda. | MVP | ✅ Implementado |
| **Comunicação & Retenção** | Como cliente, quero receber um lembrete automático via WhatsApp para não esquecer do meu horário. | Roadmap V2 | ⏳ Pendente |
| | Como profissional, quero ver o histórico de comparecimento de uma cliente (CRM) para oferecer um atendimento personalizado. | Roadmap V2 | ⏳ Pendente |
| **Financeiro & Dashboards** | Como profissional, quero ver relatórios de faturamento mensal para ter previsibilidade financeira. | Roadmap V2 | ⏳ Pendente |

---

## Divisão de Versões

### 🚀 Release 1 (MVP)
Focada no **Core Business**: a reserva silenciosa e a gestão básica de catálogos e horários. Elimina a necessidade de negociação manual via chat.

### 📈 Release 2 (Roadmap)
Focada em **Redução de No-shows** e **Gestão de Dados**: automação de lembretes, histórico de clientes e inteligência de faturamento.
